# KeyMatcher MIDI Remote Script for Ableton Live

[Devante Audio Site](www.devanteaudio.com/software/keymatcher)

Key matcher is an automatic key matcher for imported samples in Ableton Live session and arrange view.

![Settings](https://github.com/user-attachments/assets/6e602f5d-c712-44f8-98d6-fcc94f585667)

## How to use

Enter drawing mode (B), drag and drop a sample that has the key written anywhere on the name, now it's automatically adjusted to match your project key.

![Settings](https://github.com/user-attachments/assets/bbebb298-6be2-47e4-990c-e764ac1f6640)
![Settings](https://github.com/user-attachments/assets/37d15b32-9dda-4e0b-8140-71b56bc45f18)
## How to install

![Settings](https://github.com/user-attachments/assets/fa785c8c-6c3b-419b-9846-37efd4b77980)

1. Place "Launchkey_Mini_MK4_DD" and "KeyMatcher" inside your MIDI Remote Scripts folder (User Library/Remote Scripts or if that doesn't work then inside /drive_c/ProgramData/Ableton/Live 12 Suite/Resources/MIDI Remote Scripts)
2. Select the Remote Script as a Control Surface in Ableton Live (don't need to assign to a MIDI controller)
3. Done
