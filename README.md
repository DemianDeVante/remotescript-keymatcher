# KeyMatcher MIDI Remote Script for Ableton Live

Key matcher is an automatic key matcher for imported samples in Ableton Live session and arrange view.

![Settings](https://media.sweetwater.com/m/products/image/acc7a3fb4bo7mccjeDz9026wAtwwVtaO1HXw3W6L.jpg?quality=82&width=750&ha=acc7a3fb4b6dd97d)

## How to use

Enter drawing mode (B), drag and drop a sample that has the key written anywhere on the name, now it's automatically adjusted to match your project key.

## How to install

![Settings](https://media.sweetwater.com/m/products/image/acc7a3fb4bo7mccjeDz9026wAtwwVtaO1HXw3W6L.jpg?quality=82&width=750&ha=acc7a3fb4b6dd97d)
1. Place "Launchkey_Mini_MK4_DD" and "Launchkey_MK4_DD" inside your MIDI Remote Scripts folder (User Library/Remote Scripts)
2. Select the Remote Script as a Control Surface in Ableton Live (don't need to assign to a MIDI controller)
3. Done
